# Cadastro escolar de excursões

Sistema web para uma escola registrar excursões e participantes: tela de login, menu, cadastro e edição em modal, listagem e exclusão. Os dados ficam no `localStorage`, e há um esboço de conexão com MySQL em Node.

Projeto de estudo de 2023 (JavaScript), mantido aqui como registro da minha evolução.

## Como rodar

Abra o `index.html` no navegador. Para o esboço com banco: `npm install` e ajuste `scripts/db.js`.

## O que pratiquei

- CRUD completo com `localStorage`
- Modais e formulários reutilizáveis
- Primeiro contato com Node.js e MySQL
